# Expense Tracker – Java Project

A console-based Expense Tracker built using Java, File Handling, and OOP.

## Features
- Add new expenses
- View all expenses
- Monthly expense summary
- Category-wise total calculation
- File-based storage (expenses.txt)

## How to Run
```
javac src/*.java
java src.Main
```
